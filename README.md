# แอปคลิกอัตโนมัติ (Android – แท็บเล็ต/มือถือ)

ฟีเจอร์: ตั้งช่วงเวลาคลิก (+สุ่มเวลา), จำนวนรอบ, วางจุดคลิกหลายจุดด้วยการลากวงกลมบนหน้าจอ

## วิธีสร้างแอป
1. ติดตั้ง Android Studio แล้ว File > Open โฟลเดอร์ AutoClicker นี้ (รอ Gradle sync)
2. ต่อแท็บเล็ต (เปิด USB debugging) แล้วกด Run — หรือ Build > Build APK(s)

## วิธีใช้งาน
1. เปิดแอป กด "เปิดบริการ Accessibility" > เลือก "คลิกอัตโนมัติ" > เปิดใช้งาน
2. ตั้งค่าช่วงเวลา แล้วกด "บันทึก และแสดงแผงควบคุมลอย"
3. ในแผงลอย: + เพิ่มจุด (ลากไปวาง) | ▶ เริ่ม | ■ หยุด | 🗑 ล้างจุด | ✕ ปิดแผง | ⠿ ลากย้ายแผง

ต้องใช้ Android 7.0 (API 24) ขึ้นไป  ใช้ได้กับ Android เท่านั้น (iPad/iPhone ไม่รองรับ)

## สร้างไฟล์ติดตั้ง APK โดยไม่ต้องใช้ Android Studio
อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repo ของคุณ → แท็บ Actions → รัน "Build APK" → ดาวน์โหลด AutoClicker-apk (app-debug.apk)
แล้วนำไปติดตั้งบนแท็บเล็ต (อนุญาตติดตั้งจากแหล่งที่ไม่รู้จัก)
